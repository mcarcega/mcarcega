GE 4120 — Google Docs: Modern Digital Work & Collaboration

A group presentation exploring Google Docs as more than a word processor, highlighting how modern digital work involves creating, organizing, reviewing, collaborating, and managing information efficiently.

---

📋 Project Overview

- Project: Midterm Group Reporting
- Course: GE 4120
- Group: Group 5
- Topic: Google Docs
- Focus: Document management, collaboration, productivity, and digital literacy

💡 Why I Made This

This presentation was created to demonstrate how Google Docs supports modern academic and collaborative work. Rather than focusing only on its basic editing features, we explored how documents can be created, organized, shared, reviewed, and managed efficiently. We wanted to show how digital tools make teamwork more organized and help minimize confusion when working on shared projects.

🖥️ Presentation Approach

- 📄 Document creation — discussed creating, formatting, and organizing files.
- 🤝 Collaboration — highlighted real-time teamwork, sharing permissions, and reviewing.
- 🔄 Version management — explained version history and tracking document changes.
- 🔗 Google Workspace integration — explored how Docs connects with Drive, Sheets, Slides, and Forms.
- 🧠 Interactive learning — incorporated quiz questions to reinforce key concepts.

---

The skill is not just using the tool, but knowing how to manage the workflow. 💻
